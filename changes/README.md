# Changelog fragments

One file per pull request in `unreleased/`, in the format of `CHANGELOG.md` (a `### Added`, `### Changed and fixed`, `### Removed`, `### Breaking changes and upgrade` or `### Security` heading, then entries starting with `- `). The release moves them into `CHANGELOG.md` with `npm run release:prepare`; see [CONTRIBUTING.md](../CONTRIBUTING.md) and [RELEASING.md](../RELEASING.md).
