Gemini CLI free tier replaced

Gemini CLI's own quota page (geminicli.com, last updated 2026-06-18) says the unpaid tier was replaced by Antigravity CLI on 2026-06-18, while the Gemini CLI README read the same day still advertises the free tier. Not listed as an entry.

“Unpaid tier (Gemini Code Assist for individuals) and Google One users only : Gemini CLI and Gemini Code Assist IDE extensions were replaced by Antigravity CLI and Antigravity on June 18th 2026.”

“Unpaid tier and Google One users: Gemini CLI was replaced by Antigravity CLI on June 18th, 2026.”
