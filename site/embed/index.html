Use the data

Put the dataset on your own site or in your own code: a live widget, a verified badge, the full data as JSON or CSV, and a citation. All of it is MIT licensed and needs no key.

WidgetBadgesData filesCite

Live widget

A compact, always-current list of the top verified free APIs (69 verified today), ranked with the same rules as the explorer. It is one script from this site, with inline styles, no cookies and no tracking; it links back to each provider’s page here.

The snippet and the preview follow your choices. All attributes are optional; data-sort takes an explorer sort key (recommended by default).

<div id="flh-widget" data-count="6" data-modality="text"></div>
<script src="https://freellmapihub.com/widget.js" async></script>

One provider

Every provider has its own badge with the date of its last verification. Its colour follows the age of that check: green while fresh, yellow past 60 days, red past the 90-day freshness window, so a badge someone forgot never claims more than the data does. It renders through shields.io (opens in a new tab) from this site’s JSON; this page loads nothing from shields.io.

[![Groq on Free LLM API Hub](https://img.shields.io/endpoint?url=https://freellmapihub.com/badges/groq.json)](https://freellmapihub.com/p/groq)

Each provider page links here with its badge selected.

Data files

  • providers.json: every provider, every field, validated against the published schema.
  • providers.csv: the same data for spreadsheets.
  • The static JSON API: versioned endpoints and ready-made slices (no card, commercial use, by modality), described in index.json.
  • llms.txt: an index of the site for AI agents.

No key, no rate limit, no tracking on the files. Fields are only added within /api/v1/; prefer a fixed snapshot? Pin a release tag of the repository (opens in a new tab).
