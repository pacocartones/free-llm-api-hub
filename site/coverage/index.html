Pick one value

Each open item has the provider's own docs and a prefilled issue. A good contribution is one value with its source: the provider's own page, the sentence it rests on and the day you read it. Third-party summaries are not sources. Prefer an issue if you are unsure; to edit the data yourself, see the contributing guide (data is edited only in data/*.json).
