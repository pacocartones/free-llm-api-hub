Pick one value

Each open item has the provider's own docs and a prefilled issue. A good contribution is one value with its source: the provider's own page, the sentence it rests on and the day you read it. Third-party summaries are not sources. Prefer an issue if you are unsure; to edit the data yourself, see the contributing guide (data is edited only in data/*.json).

When entries come due

Every verified entry is re-checked against the provider’s own docs within 90 days. It counts as due from day 61 and past the SLA from day 91. The table counts, per week, the entries that cross each line if nobody re-checks them first. A week with more than 8 entries becoming due is a cluster: the weekly worklist pulls those entries forward, a few each week, so they do not all expire together. Weeks start on Monday (UTC), from the week of the data date. The same entries counted by the week of their last verification are on the data quality page.
