Which LLM APIs are not free

The APIs people most often expect to be free, and are not, or stopped being free. Each says what the provider’s own page says, the day it was read, and the closest free alternatives in the dataset.

No ongoing free API tier: OpenAI, Anthropic and xAI. A card or prepayment before any API use: Together AI, DeepInfra, Perplexity's API, Replicate and Featherless AI. Retired or removed after re-verification: Mistral, GitHub Models, Cerebras, Arli AI, Nebius, Hume, Clarifai, Ollama Cloud, Inference.net and Hyperbolic.

Free instead

For genuinely free access to strong models, your best bets here are Gemini (frontier-class) and the free open-weight models on Groq, OpenRouter, Cloudflare and Z.ai (SiliconFlow's free models are on its China platform and need real-name verification). Every free tier in the explorer is dated and sourced.

No ongoing free API tier

API use is paid in advance with credits and stops when they run out. Their "Free" or "Tier 0" rows are rate-limit tiers, not free usage, and any recurring API credits are promotional or come with paid plans.

OpenAI

What people expect
The rate-limits guide has a "Free" row, so the API looks free to start.
What the provider’s page says
No ongoing free API tier is established. New API accounts pay in advance; requests fail once credits run out. The rate-limits guide's "Free" row is a usage tier (allowed geography, $100/month limit), not a statement that usage is free. Promotional credits exist, including for eligible ChatGPT subscriptions, but no recurring free allowance is published.

“New API accounts use prepaid billing.”

“Prepaid billing lets you purchase credits before using the API.”

“When a prepaid account runs out of credits, API requests begin returning a billing error.”

Anthropic

What people expect
Claude has a consumer Free plan, so the API is assumed to have one too.
What the provider’s page says
No ongoing free API tier. Credits are bought before use; recurring monthly API credits come only with the paid Max, Ultra and Team plans. The consumer Free plan is chat, not API.

“Buy credits before you use the API, and they're applied to your usage according to our current pricing.”

“If you run out of credits, you can no longer call the API or use the playground until you add more.”
