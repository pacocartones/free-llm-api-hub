### Fixes in this pull request

Each fix is a separate commit:

1. **Verify order** (`RELEASING.md`, `docs/release-preparation.md`, `.github/release-template.md`):
   `npm run check -- --strict && npm test` instead of `npm test && npm run check -- --strict`. On a
   clean checkout of a tag the old order fails four tests before anything has built the pages they
   read. The new order passed 1335 of 1335 on a clean worktree.
2. **PR citations** (`changes/unreleased/`): 42 entries in 17 fragments cited no pull request,
   which rule 5 requires. Each now cites the pull request that added its fragment, worked out from
   the merge history. The ElevenLabs `models_url` entry (#867) now also thanks its outside
   contributor.
3. **Guardrail count** (`changes/unreleased/add-plamo-entrim-infomaniak.md`): two fragments gave
   different counts of providers with no `text` modality. The stale one (25 of 77) is gone. The
   current one, 25 of 79 (31.6%), matches the data.

### Blockers and decisions

**Hard blockers to tagging: none.** The checks above pass on current `main`, and the release
pull request tooling works end to end. Before or on 2026-12-04:

1. **The release pull request can only be prepared on 2026-12-04 (UTC).** `release:prepare`
   refuses a date after today, and `validate.mjs` rejects a `generated` date in the future. A pull
   request prepared on the rehearsal day (03-12) would be dated 2026-12-03. Prepare it on 04-12,
   or accept the 03-12 date.
2. **The owner's OK names the cadence reason.** Rule 9 (c) applies: 14 days since v2.14.2
   (2026-11-20 → 2026-12-04), with many minor changes users would notice. No other minor release
   ships that week.
3. **Two themes from the brief are not merged yet.** Provider batch 8 (#936: Requesty, Kilo
   Gateway, Experiential Labs) and the "not stated" wording refactor (#929) are open. They are in
   v2.15.0 only if they merge before the release pull request; otherwise they go to the next
   release. The draft below includes neither, and has placeholders for them.
4. **Draft v2.16.0 work must wait.** #774, #775 and #933 must not merge before the release pull
   request.
5. **Data or fragments merged after this draft.** Run `npm run changelog-draft`, then re-check the
   Contributors section against the pull requests merged up to the release commit (rule 5). Two
   open pull requests from outside contributors could merge in time: #931 and #934.
6. **The Verify section needs its values at the tag:** the data commit, the snapshot `toolingCommit`
   and Node version, and the SHA-256 of `providers.canonical.json`. Fill them in from
   `npm run release-snapshot -- v2.15.0 <dir>` once `Tag release` has created the tag.
7. **Refresh `CONTRIBUTORS.md` with `npm run contributors`.** This was not run here: it needs
   `gh pr list`, which this environment cannot call. The first-time contributors below come from
   the merge history and the GitHub search API.

**v2.15.0 — 17 new providers, the Cálida redesign, answer-first provider pages and `/api/v1/status.json`**

This release adds 17 providers, bringing the dataset to 79 (from 62). It records *why* each
tri-state flag holds its value (`field_checks`) and adds a per-provider freshness file,
`/api/v1/status.json`. On the site: the warm "Cálida" redesign, answer-first provider pages with a
FAQ, model and model-family pages, and valid structured data. Every change to the data and the API
is additive. If you validate against `/api/v1/schema.json`, refresh your copy: it now accepts fields
added within v1 (#760). No action is needed otherwise.

No breaking changes.

### Added

- **17 providers.**
  - Speech, image and audio: Azure Speech (Free F0) and Lemonfox.ai (#755), Stability AI (#805).
  - Open-model and gateway APIs: Inception (Mercury) and Aion Labs (#741); Regolo.ai and Google
    Gemini Enterprise Agent Platform express mode (#714); MegaNova AI and SEA-LION API (#750); Bytez,
    Liquid AI and Public AI Inference Utility (#790); PLaMo API, Entrim and Infomaniak AI Services
    (#816).
  - Provider batch 7: Berget AI and Netlify AI Gateway (#903).
  - *[If #936 merges first: provider batch 8, Requesty, Kilo Gateway and Experiential Labs (#936).]*

  25 of the 79 providers (31.6%) list no `text` modality, under the 35% non-text guardrail.
- **`field_checks`.** For each tri-state flag (`phone_required`, `card_required`, `commercial_ok`,
  `openai_compatible`), a provider can record the pages read, the day, and either the provider's
  sentence or why the flag stays `null`: `source_silent`, `needs_account` or `sources_disagree`.
  Provider pages, comparisons, `/coverage/` and the MCP server show the reason (#719). Batches of
  checks were recorded across the dataset (#707, #726, #730, #738, #743), and `openai_compatible`
  now has its reasons too (#785, #797, #895).
- **`/api/v1/status.json`.** Freshness per provider, keyed by slug: `last_verified`, the oldest field
  check, the state against the 60/90-day SLA, `free_now` and the newest field change. It has a JSON
  Schema and is purely additive (#918).
- **More fields:**
  - `published_speed`, the speed a provider publishes, quoted word for word (#728, #733);
  - `keys_url`, with a "Get a free key" button on provider pages (#810, with key pages added in
    #836–#841 and #851–#858);
  - `models_url`, a link to the provider's official model catalogue (#773, #822, #833–#835,
    #860–#867, #869);
  - anonymous access, with a "no account needed" collection (#731, #737).
- **Provider pages answer first.** They open with "Is \<Provider\> API free?", answered in one or two
  sentences built from the data. A field the dataset leaves null reads "not stated". Each page ends
  with a six-question FAQ, mirrored as `FAQPage` JSON-LD (#927). They also lead with the quickstart
  (#789) and have a Markdown version at `/p/<slug>.md` (#901).
- **Model and model-family pages.** There is one page per model in the free-model samples
  (`/models/<key>/`, #711). Family pages at `/free-api/<family>/` (Qwen, Gemma, DeepSeek, Llama,
  GPT-OSS, GLM) answer "where can I use it for free via API?" (#922).
- **New pages:**
  - "Find my free API" at `/find/`, a six-question wizard (#817);
  - `/not-free/` and `/embed/` ("Use the data"), with the widget, badges and a Cite block (#787);
    the Cite block is also on `/api/` and `/quality/` (#868);
  - the public `/quality/` page (#765);
  - long-form guides by modality and by use case (#808, #820, #898).
- **Dataset discoverability.**
  - Generated `Dataset` JSON-LD and a public change history (#717).
  - Mirrors to Hugging Face and Kaggle on each release (#716).
  - The prompt data policy in `llms-full.txt` (#807), and the commercial-use condition there (#736).
  - Publisher and creator in the structured data, and a sitemap index (#764).
  - A provider badge as HTML (#849).
  - IndexNow pings after each deploy (#721).

### Changed and fixed

- **The Cálida brand.** The new look, "Fingerprint + Receipts", uses a warm palette, Roboto Flex
  and DM Mono (#844):
  - each provider gets a generative *aura* drawn from its record (#845);
  - the verified date is shown as a *receipt* that links to the page it was checked on (#845);
  - there is a new brand mark, and the home hero and provider pages are redesigned (#846);
  - social images, the README banner and badges follow the new look (#847), and so does the embed
    widget (#932).

  Every colour keeps WCAG AA contrast in both themes.
- **Home page and explorer.** The home page has one hero action, one control bar and a shorter table
  row (#892). It also has a first-use strip and an intent-ordered ranking (#720, #786), and keeps
  its server-rendered rows on first paint (#754). Fixes for mobile layout and table semantics: #739,
  #891, #902.
- **Structured data and SEO.** The structured data now passes Google's Rich Results Test (#904), and
  `/coding-tools/` gained its JSON-LD (#859). Retired URLs redirect (#890), crawler policy lives in
  `robots.txt` (#767), and `llms.txt` was reorganised (#901). Performance and security headers:
  #724, #735.
- **Re-verification.** Re-verification is now staggered weekly, and a freshness histogram shows the
  ages (#766).
  - Batches: #701, #723, #734, #791, #818, #875, and the eight stalest entries in #925.
  - Data policies recorded or corrected: #692, #698, #708, #729, #783, #870.
  - Free limits and terms re-read: #685, #688–#691, #697, #722, #725, #776.
  - Every entry, with its dates and sources, is in `CHANGELOG.md` under `## [2.15.0]`.
- **The API schema accepts fields added within v1.** `/api/v1/schema.json` sets
  `additionalProperties: true`, so strict validators accept `field_checks`, `published_speed` and
  `anonymous_access` (#760).
- *[If #929 merges first: null values read "not stated" and dates read "24 Nov 2026" everywhere
  (#929).]*
- **Project and tooling** (no change to the data):
  - Derived files are regenerated after merge by a bot. Data pull requests no longer ship them, and
    the required check regenerates before it checks (#715, #742, #809, #823, #935).
  - CI is faster: npm cache, one build in push mode, and Lighthouse skipped when the site cannot
    change (#921).
  - The release stamp moves only with the version (#702).
  - The maintainers' shared open-source standard v2 covers issue forms, reply goals and the
    good-first-issue cap (#917).
  - A weekly report-only source watch checks for quote drift (#771), and monthly issues are opened
    for free-tier changes and provider candidates (#784).

```bash

```
