# AI policy

**Contributions made with the help of AI are welcome here — warmly.** Use whatever tools help you: coding assistants, chat models, agents, translation. Many good first contributions start that way, and we'd rather you send a useful change with help than not send it at all.

What we ask for is the same thing we ask of every contribution: **good human judgement.**

## What we ask

- **Understand what you send.** Read the change before you open the pull request, and be ready to explain it and answer review questions in your own words.
- **Test it.** Run the project's checks locally (see CONTRIBUTING) and say what you ran.
- **Check facts at the source.** AI tools can invent numbers, links and quotes. Every claim must come from a source you opened yourself. In this repository, every data change needs a link to the provider's own page and the date you checked it.
- **Own the change.** You are responsible for what you submit, whoever or whatever helped write it. Keep pull requests focused: one change, one reason.
- **Keep secrets out.** Don't paste API keys, private data or anything confidential into AI tools.

## Telling us is optional

You don't have to tell us you used AI, and it never counts against you. If you'd like to, there's a checkbox in the pull request template. It simply helps reviewers know where to look more carefully. We review every pull request on its merits, by the same standard.

## How we work

We maintain this project with the help of AI agents too, under human oversight. Agents do much of the routine work: re-checking sources, preparing updates, triaging issues and drafting code. A human maintainer reviews and is responsible for every merge. Automated review comments are advisory; a person makes the call.

## What we will close

The same things we would close from anyone: changes nobody seems to have read or run, invented sources or data, or pull requests that ignore the issue they claim to fix. If that happens, we'll say why, and you're welcome to try again.

Questions? Open an issue or a discussion. We're happy to help.
